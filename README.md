## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors for Windows. It bundles multiple executors and a universal loader so you can manage and switch between them from a single interface.

### Is XCutors free to use?

Yes. The XCutors package itself is free and open-source. Some individual executors included may have their own licensing or premium tiers – please check each executor's original page for details.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions such as Windows 7 or 8 may work but are not officially supported.

### Why does my anticomponent flag the files?

Roblox executors modify game memory, which is behavior commonly flagged by anticomponent heuristics. These are false positives. You can whitelist the XCutors folder or add it to your exclusion list.

### How do I update the executors?

Run xcutorsLoader.exe and use the built-in update checker. Alternatively, download the latest release from the GitHub Releases page and replace your existing files.

### Does this work on all Roblox games?

XCutors supports script execution in most Roblox experiences. However, some games with advanced anti-tamper protections may block certain executor features.

### Where can I find scripts to use?

Community script hubs are built into each executor. You can also find scripts on popular Roblox scripting forums and repositories. Always review scripts before executing them.

### Can I use multiple executors at the same time?

Only one executor should be injected per Roblox session. The universal loader allows you to switch between executors without restarting the application.

### I'm getting an injection error. What should I do?

Ensure Roblox is running and fully loaded into a game before injecting. Run the executor as Administrator, check that your anticomponent is not blocking it, and verify you have the latest version.
